# Clip v2.6: Universal Input

Clip v2.6 introduces one command for whatever is currently on the clipboard:

```sh
clip --auto
```

## Automatic routing

| Clipboard content | Pipeline |
|---|---|
| Image | Private temporary image → layout-aware offline OCR |
| Existing local file or directory path | File detection → parser/OCR → renderer |
| Public HTTPS document URL | Bounded private download → parser/OCR → immediate cleanup |
| Plain text | Renderer → optional rich output or AI-ready chunks |

Image representations take precedence when an application publishes both image and text clipboard formats. Local paths take precedence over URL parsing. No watcher, daemon, or history database remains after the command exits.

## Composable output

Universal input supports the same controls as the document pipeline:

```sh
clip --auto --smart
clip --auto --layout exact --rich
clip --auto --format markdown --stdout
clip --auto --format jsonl --chunks 1200 --output context.jsonl
clip --auto --recursive --output corpus.md
```

`--auto` reads its source from the clipboard and therefore does not accept a positional filename. Explicit source modes such as `--screen`, `--image`, `--pdf`, `--clipboard`, and `--watch` remain available when deterministic routing is preferred.

## Security model

- Clipboard sensitivity is checked before reading image or text bytes.
- Images retain Clip's encoded-size, decoded-dimension, pixel-count, and OCR-time limits.
- Remote input accepts HTTPS only and rejects embedded URL credentials.
- DNS results and every redirect are blocked if they target loopback, private, link-local, multicast, or unspecified networks.
- Remote response declarations and streamed bytes are both limited to 50 MiB.
- TLS 1.2 or newer is required.
- Downloads use a mode-0700 temporary directory and a mode-0600 file, then remove the complete workspace.
- Extraction and OCR remain local; Clip performs no upload and uses no cloud OCR API.

## Why this matters

Instead of remembering separate commands for screenshots, copied files, downloaded documents, and text conversion, users can bind `clip --auto` to a terminal alias or system shortcut. Clip determines the input type while the user continues to control format, destination, structure, and privacy.
