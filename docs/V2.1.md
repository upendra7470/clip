# Clip 2.1: Layout-Aware OCR

Clip 2.1 makes images and PDFs first-class, layout-aware inputs while retaining the existing automatic command syntax.

```sh
clip --image receipt.png
clip --pdf report.pdf
clip --pdf --layout exact report.pdf
```

`clip receipt.png` and `clip report.pdf` remain fully supported.

## Layout modes

- `auto` is the default. It restores reading-order lines, paragraph breaks, and tab-sized column or table gaps.
- `plain` keeps reading-order lines but normalizes horizontal spacing.
- `exact` uses bounded spaces to approximate the original horizontal positions in monospaced text.

Digital PDF pages are reconstructed from text coordinates. Scanned pages use the bundled OCR engine's word geometry. Mixed PDFs combine both strategies page by page and preserve page boundaries.

## Output guarantee

Clip preserves logical plain-text structure: words, lines, paragraphs, columns, tables, and pages. A plain-text clipboard cannot preserve fonts, colors, images, or pixel-perfect styling. Markdown output can additionally represent detected tabular rows.
