# Clip v2.5: Instant Clipboard OCR

Clip v2.5 adds a one-shot OCR command for the image already stored on the clipboard.

## Command

```sh
clip --clipboard
```

Copy a screenshot or image, run the command, and Clip replaces it with recognized text before exiting. Unlike `clip --watch`, no long-running process remains active.

Existing OCR and output controls compose with the command:

```sh
clip --clipboard --smart
clip --clipboard --layout exact
clip --clipboard --format markdown --rich
clip --clipboard --format json --stdout
```

`--clipboard` does not accept a filename and cannot be combined with file-input modes, directory recursion, chunks, or `--output`.

## Privacy and safety

- Clipboard content marked sensitive is refused before its image bytes are read.
- Encoded and decoded image safety limits remain enforced.
- OCR runs entirely offline with the bundled engine.
- The private temporary image is removed immediately after OCR.
- No watcher, daemon, history database, or background process remains after the command exits.

## When to use each command

| Workflow | Command |
|---|---|
| OCR the image already copied and exit | `clip --clipboard` |
| Keep recognizing future copied images | `clip --watch` |
| Select a visible screen region directly | `clip --screen` |
