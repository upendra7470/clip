# Clip 2.0 preview

Clip 2.0 turns the original clipboard utility into a reusable, local-first document pipeline while preserving `clip <file> [range]`.

## Implemented in this pull request

| Capability | Command |
|---|---|
| Smart OCR cleanup and orientation | `clip --smart scan.png` |
| Structured Markdown | `clip --format markdown --stdout report.pdf` |
| JSON document envelope | `clip --format json --stdout report.pdf` |
| AI-ready JSONL chunks | `clip --format jsonl --chunks 1200 --stdout report.pdf` |
| Directory batches | `clip --recursive --output corpus.md ./documents` |
| Shell completion | `clip --completion bash` |
| Rich clipboard paste | `clip --rich --pdf report.pdf` |
| Searchable scanned PDF | `clip --make-searchable scan.pdf` |
| File-manager templates | See [`../integrations/`](../integrations/) |

Smart OCR applies grayscale conversion, percentile contrast normalization, high-quality upscaling for small scans, and four-way orientation scoring. Processing remains offline and uses the engine embedded in official Clip releases.

Batch output is deterministic, ignores unsupported extensions, and stops at 1,000 files. JSON/JSONL is emitted with stable fields, while chunking counts Unicode code points and prefers whitespace boundaries.

Rich copy publishes safe HTML and plain text in one native clipboard operation, allowing formatting-aware applications to preserve document structure without breaking terminal or editor paste. Searchable-PDF export keeps the source page appearance and adds a zero-opacity OCR text layer only where native text is absent. The output defaults to `<name>.searchable.pdf`, never overwrites an existing file, and is published atomically.

## Language coverage

The bundled model automatically recognizes printed Latin-script text and accepts hints for English, French, German, Spanish, Italian, Portuguese, and Dutch. The architecture now carries the language selection through the extraction request, allowing future model packs to add writing systems such as Devanagari, Arabic, CJK, and Cyrillic without another CLI redesign.

Non-Latin model packs are deliberately not advertised as complete in this preview.

## Compatibility

The classic command, range syntax, clipboard behavior, supported formats, and self-contained release process remain compatible with Clip 1.x. New behavior is activated only by v2 flags or a directory input.
