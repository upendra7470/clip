# Clip 2.2: Instant Screen OCR

Clip 2.2 can copy text from anything visible on screen:

```sh
clip --screen
```

Select a region with the mouse. Clip captures it privately, performs the same offline layout-aware OCR used for images, sends the result to the clipboard, and deletes the screenshot.

```text
Select an area of the screen…
✓ Captured 1240 × 680
✓ Recognized 247 words
✓ Sent to clipboard
```

## Output options

Screen OCR supports the normal Clip workflow options:

```sh
clip --screen --layout exact
clip --screen --format markdown --stdout
clip --screen --chunks 1200 --output capture.jsonl --format jsonl
clip --screen --smart
```

## Platform behavior

- **Windows:** a built-in Windows Forms overlay captures the selected rectangle using the native screen API.
- **macOS:** the system Screen Capture selector is used. macOS may request Screen Recording permission on first use.
- **Linux X11:** Clip's compiled-in X11 pointer selector captures the chosen rectangle directly.
- **Linux Wayland:** the standard `xdg-desktop-portal` screenshot interface provides the permission dialog and interactive selection.

No OCR service, screenshot package, Tesseract installation, or ImageMagick installation is required. All recognition remains offline. Clip-owned temporary screenshots use private permissions and are removed immediately after processing; Wayland portal implementations manage their own portal-owned image lifecycle.

Press Escape in the Windows or macOS selector, or cancel the Wayland portal, to stop without capturing. On X11, click without dragging to cancel.
